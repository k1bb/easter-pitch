# Easter Vigil Pitch Prompter

A mobile web application designed for Catholic priests celebrating the Easter Vigil in Japan.

It provides reference audio pitches for:
- **The Showing of the Paschal Candle** (*Lumen Christi* / キリストの光)
- **The Easter Proclamation** (*Exsultet* / 復活賛歌) solo chants

---

## Usage

During the Easter Vigil in the darkened church, the priest wears a discrete wireless earphone. An altar server (or assistant) taps the buttons on a smartphone to quietly feed the reference pitch into the priest's ear.

- **Hold to play**: The sound plays while the button is held down. The final note sustains until released, then fades out smoothly.
- **Designed for darkness**: True black background (OLED) with soft candlelight tones to prevent glare in the dark church.
- **Single screen**: All buttons fit on one screen without scrolling.
- **Works offline**: PWA with offline caching.
